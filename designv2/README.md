## 🛠️ Scripts & Reproducibility (`scripts/`)

- `enrich_figma_v3.js` — OpenPencil automation script that reads `pkn-mobile-v2.fig` and builds `pkn-mobile-v3.fig` deterministically:
  ```bash
  # Rebuild pkn-mobile-v3.fig from pkn-mobile-v2.fig
  cp designv2/pkn-mobile-v2.fig designv2/pkn-mobile-v3.fig
  cat designv2/scripts/enrich_figma_v3.js | /home/abuhafi/.local/bin/openpencil eval designv2/pkn-mobile-v3.fig --stdin -w --json
  
  # Re-export visual artboards
  /home/abuhafi/.local/bin/openpencil export designv2/pkn-mobile-v3.fig -o designv2/exports/00-cover-architecture.png --page "00 - Cover & Architecture"
  /home/abuhafi/.local/bin/openpencil export designv2/pkn-mobile-v3.fig -o designv2/exports/03-main-app-screens.png --page "03 - Main App Screens (Light & Dark)"
  /home/abuhafi/.local/bin/openpencil export designv2/pkn-mobile-v3.fig -o designv2/exports/04-interactive-modals-flows.png --page "04 - Interactive Modals & Flows"
  ```
- `build_all.mjs`, `design_tokens.mjs`, `pages_*.mjs` — Baseline FigCraft code generators for v2.
